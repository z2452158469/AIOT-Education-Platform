# 创客社团 · 社团教学平台 V1

轻量可交互演示版。学生与指导教师拥有个人空间，首页聚焦我的项目和待办事项，学习任务和技术社区通过侧栏进入。通过侧栏进入成果展示与虚拟实验室，点击头像进入个人档案。虚拟实验室暂留空白，后续补充功能。

## 本地运行

推荐使用 Node.js 启动（无需安装依赖）：

```sh
git clone https://github.com/z2452158469/AIOT-Education-Platform.git
cd AIOT-Education-Platform
node serve.mjs
```

在浏览器访问 http://localhost:4174，选择学生或指导教师身份即可体验。

也可使用 Python：`python -m http.server 4173 --directory dist`，访问 http://localhost:4173；这种纯静态方式不支持 AI 助手接口。

## DeepSeek 学习助手

助手位于待办事项下方，固定学习小组位于个人信息下方、学习日历上方。助手提供连续对话、学习提示和可选项目背景；项目背景默认不选，只发送对话以及主动选择的项目标题和简单描述，不附带个人资料、成员名单或签到记录。对话按演示身份保存在当前浏览器会话中，可点击“新对话”清空。

使用 Node.js 20.6 或更高版本。将根目录 `.env.example` 复制为 `.env`，在本机编辑 `.env` 中的 `DEEPSEEK_API_KEY`，然后运行：

```powershell
Copy-Item .env.example .env
# 编辑 .env，填写 DEEPSEEK_API_KEY；不要将真实密钥写进 dist/ 或提交到仓库。
node --env-file=.env serve.mjs
```

配置文件默认地址为 `https://api.deepseek.com`、模型为 `deepseek-flash`，可在 `.env` 中修改 `AI_BASE_URL` 和 `AI_MODEL`。接口格式依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/quick_start/agent_integrations/)；密钥只由 Node 服务端读取。修改配置后需重启服务，页面可点击“刷新状态”。界面显示“已配置”仅代表服务端已读取配置，实际请求中的认证或余额问题会在提问时提示。

请求包含最近最多五轮成功对话（超出总长度时裁剪较早对话），单次问题限 2000 字，附带项目背景限 2000 字；服务器设有大小限制、同源校验、请求超时和限流。失败时保留问题，不生成模拟回复。服务默认仅监听本机 `127.0.0.1`，尚无正式账号鉴权，不能直接公开部署为多人 AI 服务。

无需额外依赖。可运行 `node tests/navigation.cjs` 和 `node tests/ai-api.mjs` 验证界面逻辑与 API 转发；API 测试使用模拟响应，不调用真实 DeepSeek，也不消耗额度。真实调用需提供有效密钥。

## 界面配色

品牌主色为紫色 `#7040C8`。项目以高饱和度彩色卡片展示，按项目 ID 稳定分配紫、蓝、青绿、橙、玫红五种底色；待办、AI 助手、小组、日历和个人资料使用各自的辅助色。卡片右上角的配色按钮支持从 20 种颜色中选择，或恢复自动配色，手动颜色随项目保存在原有 `zhixing-v1` 本地存储中。

卡片以单人 / 多人图标区分个人项目与合作项目。首页“我的项目”将当前身份最后打开的项目置顶，标注“最近项目”并铺满项目区域一行，下方仅展示其余项目。最近打开记录按身份保存在当前浏览器，刷新后保留；尚未打开项目时保持普通网格。详情页左侧列表保留原有排列。

## 已实现

- 学生 / 教师演示身份选择，进入个人空间；刷新保留本次会话。
- 学习任务和技术社区页面使用统一的独立标题区；欢迎语与置顶公告仅在个人空间首页展示。
- 技术社区沿用原帖子数据与链接，支持发布、搜索、点赞和评论。
- 成果展示支持全部 / 我的成果、发布标题和介绍、上传附件、详情查看及本人编辑和删除。最多 3 个附件，每个 500 KB，支持下载；保存在当前浏览器。
- 虚拟实验室提供独立页面与空白内容区。
- 点击顶部或个人信息卡头像进入个人档案，展示资料、学习与创作统计、个人项目和成果，可编辑原有个人资料。手机端提供五个板块的导航入口。
- 个人首页展示自己的项目与待办，支持项目创建、编辑和分栏详情。
- 创建项目只需标题、简单描述、项目类型（个人 / 合作）和规模（练习 / 实践 / 工程）。个人项目仅本人可见；合作项目创建者在详情中设置项目成员，组员可共同查看和编辑，成员设置仅创建者可更改。旧项目默认迁移为个人练习项目，保留已有内容。
- 学生添加个人待办，教师添加个人或全员待办；按人记录勾选状态，逾期未完成事项标红，仍可完成。
- 学习日历支持切换月份、选择日期，展示并勾选当天截止的待办事项。
- 学习日历上方展示“我的小组”，使用独立固定名单，由教师管理名称和成员，项目成员变化不会影响此名单。首次升级合并已有合作项目成员，无合作项目时使用演示成员；保留已有课堂和签到记录。可查看当前浏览器会话在线状态，按当天不同课堂为同组成员签到，记录本人 / 代签人及时间，防止重复签到。在线状态每 30 秒刷新，超过 75 秒未更新视为离线；跨设备状态同步和正式签到校验尚需后端。
- 待办下方提供 DeepSeek AI 学习助手，支持连续提问、项目背景选择、失败重试、新对话和按身份隔离的会话记录。
- 教师发布、编辑任务；学生提交文字和附件、保存草稿、重新提交；教师评价与退回修改；历史提交。
- 学习任务与任务状态筛选、截止时间提示。
- 任务和帖子使用左侧列表、右侧详情的分栏布局，点击后滑动展开，支持列表内切换、链接直达、刷新、浏览器前进后退和返回列表；窄屏上下排列。
- 帖子发布、编辑、搜索、分类、点赞、评论；本人删除自己的内容，教师管理及置顶。
- 教师公告发布、编辑、置顶、删除，学生查看。
- 个人资料、学习统计、当月任务日历，适配手机。
- 主页和详情页使用全宽自适应画布；宽屏主页按约 62% / 38% 并排展示项目和待办，待办使用紧凑行距；左侧导航切换带淡入上移动画，并尊重系统减少动态效果设置。详情左右栏占满可用高度并独立滚动，平板、手机和低高度窗口自动调整布局。

## 版本边界

这是浏览器本地演示，身份选择不是安全认证。示例数据仅用于体验。数据使用 localStorage 保存，身份使用 sessionStorage 保存，同源标签页共享内容；不同设备、浏览器和访问地址不共享数据。请勿存放真实学生资料。附件最多 3 个、单文件 500 KB，受浏览器总存储额度限制。附件支持下载，暂不提供图片内嵌预览。正式使用需接入服务端身份验证、权限校验、数据库和文件存储。没有后端用户账号管理或真实通知推送。

无需构建或安装依赖，静态入口为 dist/index.html。页面字体优先加载 Noto Sans SC，离线自动回退系统字体。
